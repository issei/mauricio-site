# TGI sobre EDI (2004) — especificação da página de portfólio

Especificação da futura página `src/tgi-gestao-de-pedidos-edi.html`, que apresenta o Trabalho de
Graduação Interdisciplinar **"Gestão de Pedidos utilizando a tecnologia EDI"** (Maurício Miranda
Issei, Priscila Machado Momma e Sergio Kameoka; Universidade Presbiteriana Mackenzie, 2004) em três
camadas separadas: o trabalho original, uma análise retrospectiva e uma atualização técnica.

> **Status:** especificação. A página não foi implementada nem publicada.

## Onde está o original

O ZIP original e as extrações de trabalho ficam na pasta do projeto, **fora deste repositório**:
`/mnt/project-files/estudos/tgi-edi-2004/`. O repositório é público, e a publicação do documento
completo depende do consentimento dos coautores (questão Q-1 da spec C).
