[0:00]Olá, hoje a gente vai mergulhar fundo para desvendar um dos campos mais fascinantes da tecnologia, o machine learning ou aprendizado de máquina. Vamos entender de uma vez por todas como é que as máquinas realmente aprendem a pensar. Para começar, vamos pensar numa coisa do nosso dia a dia. Sabe quando um serviço de streaming parece adivinhar exatamente o filme que a gente tá com vontade de ver ou a música perfeita para aquele momento? Pois é, a resposta para essa mágica tá em grande parte no machine learning. Certo? Então vamos aprofundar um pouco pra gente entender como eles chegam nessas recombinações tão precisas. Primeiro a gente precisa definir o que é exatamente o machine and learning e mais importante como ele é diferente da programação que a gente conhecia até então. Basicamente machine learning é uma forma de ensinar computadores a aprender. Em vez da gente dar um conjunto de instruções super rígidas, a gente alimenta a máquina com um monte de dados e a partir daí ela mesma descobre os padrões. É um ramo da inteligência artificial, sabe? Um passo importantíssimo para criar sistemas que

[1:01]são de fato inteligentes. E olha, esse slide aqui mostra essa virada de chave de um jeito brilhante. Na programação tradicional, o desenvolvedor escreve o código tipo: "Se acontecer X, faça Y". É tudo explícito. Como machine learning, o jogo vira. O computador recebe milhares de exemplos de X e Y e ele mesmo aprende qual é a relação entre eles. É diferença entre receber um manual de instruções e aprender com a experiência, tá? Mas como é que se ensina uma máquina na prática? Existem várias abordagens, mas a maioria delas se encaixa em duas grandes categorias. Vamos dar uma olhada agora em como isso funciona com aprendizado supervisionado e o não supervisionado. A diferença crucial aqui tá nos dados. No aprendizado supervisionado, cada pedaço de informação que a máquina recebe já vem com a resposta certa, com um rótulo. É como se fosse um professor dando exemplos com o gabarito. Já no supervisionado, a máquina recebe um monte de dados cruz, sem rótulo nenhum. E a tarefa dela é encontrar uma estrutura ali sozinha, tipo grupar

[2:02]coisas que são parecidas. Um exemplo super clássico de aprendizado supervisionado é a tal da regressão linear. Se a gente pegar dados históricos de vendas e outros fatores, tipo o quanto foi gasto em marketing, dá para treinar um modelo para prever as vendas do futuro. O modelo aprende a relação entre essas variáveis para fazer uma estimativa bem formada. Agora mudando pro lado não supervisionado, temos algoritmos como o Keins. E o que é bem interessante aqui é essa citação que resume a essência dele. O Camins não tá tentando prever um valor, ele tá organizando os dados. Ele encontra grupos naturais ali no meio da bagunça, sem ninguém precisar dizer para ele quais grupos ele deveria procurar. E aqui a gente fecha o círculo. Voltando pra nossa pergunta lá do começo, é exatamente isso que os serviços de streaming fazem. Eles usam algoritmos de clusterização, como o Keins, para juntar pessoas com gostos parecidos em grupos. Se um monte de gente do grupo A gostou de um filme, a chance de outras pessoas daquele mesmo grupo gostarem também é

[3:04]altíssima. Beleza, a teoria tá fazendo sentido, mas como isso funciona na prática, no dia a dia de quem trabalha com isso? Criar um modelo de machine learning é um processo bem estruturado. É como ter uma caixa de ferramentas completa à disposição. O fluxo de trabalho geralmente segue esses passos aqui. Tudo começa com os dados que, olha, quase sempre precisam de uma boa limpeza. Depois vem a escolha do algoritmo certo pro problema e existem dezenas. Aí vem a parte do ajuste fino para otimizar o modelo e por fim a avaliação para ter certeza de que o modelo vai funcionar direitinho no mundo real. E só para ter uma ideia visual desse tipo de processo, dá uma olhada nesse fluxograma. Ele mostra um algoritmo genético que é inspirado na evolução natural. Ele cria uma população de soluções e vai evoluindo elas, cruzando, fazendo mutações e selecionando as melhores a cada geração. Isso mostra como a criação de um modelo é um processo que se repete e às vezes é bem complexo. Durante essa etapa de ajuste, um dos maiores desafios é achar

[4:05]o equilíbrio perfeito. Se o modelo for simples demais, ele pode acabar ignorando informações importantes. Isso é o que chamamos de underfeing. Agora, se ele for complexo demais, ele pode decorar os dados de treino, incluindo ruído, e não funcionar bem com dados novos. Isso é o overfeiting. O ouro tá em achar o meio termo e a chave para encontrar esse equilíbrio tá nos hiperparâmetros. Essa citação descreve o papel deles de uma forma perfeita. Eles não são aprendidos com os dados, eles são definidos antes do treino. Pensa neles como os botões de um rádio que a gente vai ajustando para encontrar o sinal mais limpo, ou seja, o melhor desempenho do modelo. OK? Com essa base toda, vamos ampliar um pouco nosso olhar. Machine learning não é só um conceito acadêmico, não. Ele já tá remodelando indústrias inteiras e levantando perguntas bem importantes sobre o futuro da tecnologia. E é sério, o ML tá em todo lugar mesmo, desde o sistema que aprova ou nega uma compra no cartão de crédito em segundos até os anúncios que aparecem no celular. Cada uma dessas aplicações usa os princípios que a gente conversou

[5:06]para tomar decisões inteligentes o tempo todo. E isso nos leva a uma questão que é, talvez a mais fundamental de todas. Conforme a gente delega mais e mais decisões para esses sistemas, a confiança se torna a palavrachave. Se um modelo nega um empréstimo ou ajuda num diagnóstico médico, a gente precisa ter como entender o porquê daquela decisão. E é aqui que a gente entra no grande debate entre os modelos caixa preta e os modelos interpretáveis. Uma caixa preta, tipo uma rede neural super complexa, pode ser incrivelmente precisa, mas o processo de decisão dela é tão complicado que é quase impossível para um humano entender. Já o modelo interpretável é pensado desde o início para ser transparente, mesmo que isso teoricamente signifique abrir mão de um pouquinho de complexidade. Durante muito tempo, a ideia geral no campo era exatamente essa, que existe uma troca. Se a gente quisesse o máximo de precisão, teria que aceitar a complexidade de uma caixa preta. Agora, se o objetivo fosse entender o modelo, a

[6:06]gente teria que aceitar um modelo um pouco menos preciso. E pra gente terminar, uma ideia provocadora que tá mudando tudo. Pesquisas mais recentes estão argumentando que essa tal troca pode ser um grande mito. A nova fronteira da pesquisa em machine learning agora é buscar o melhor dos dois mundos. modelos que não sejam apenas super precisos, mas que também sejam transparentes. A pergunta que fica é: como a gente consegue construir sistemas em que se confia não só no resultado, mas também no processo? Isso redefine completamente o que a gente pode esperar da inteligência artificial.
